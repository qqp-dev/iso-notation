# Ticket: Printable Columnar Score Engine & Network Laser Printing Pipeline

## Kind

bounded — print layout engraving, columnar pagination for A4/2-page spread, web print CSS, and network laser printing pipeline via nacho-pi to Brother HL-L3300CDW.

## Problem

The operator has requested:
1. Figure out how the vertical isomorphic notation prints on physical paper (A4 portrait base, 2-page spread / A3 landscape).
2. Implement the columnar print layout (8 measures per column, 2 columns per page: Section A mm. 1–16 on Page 1, Section B mm. 17–32 on Page 2).
3. Connect and send the print job over the network:
   - On the operator's phone (`pixel-10`), via standard browser print dialog (`window.print()` / `@media print`).
   - From `nacho-pi` (`100.118.214.29`), directly streaming PostScript/PJL to the local Brother HL-L3300CDW laser printer at `192.168.4.62:9100`.

## Testing plan

1. **Columnar Engraving Geometry Invariant**:
   - Total measures: 32 (Goldberg Variation 1).
   - Exact 4-column distribution (8 measures per column):
     - Column 0: Measures 1–8 (ticks 0–384)
     - Column 1: Measures 9–16 (ticks 384–768)
     - Column 2: Measures 17–24 (ticks 768–1152)
     - Column 3: Measures 25–32 (ticks 1152–1536)
   - Pages: Page 1 holds Cols 0 & 1 (Section A); Page 2 holds Cols 2 & 3 (Section B).
   - Zero page turns across each 16-measure section.
2. **High-Contrast Print Topography & Morphology Invariant**:
   - Pure white background (`#FFFFFF`) for paper savings and high-contrast readability.
   - Monochrome 3+3 staff lines: bold octave (PC 0, 1.5pt), dashed tritone (PC 6, 1.0pt, dash 3 3), hairlines (PC 2, 4, 8, 10, 0.5pt).
   - Solid row-parity noteheads with white halo knockout: discs on lines (Row 0), diamonds in spaces (Row 1).
   - Unified Euclidean duration lattice: pure unextended noteheads for 16th notes ($d \le 12\text{t}$); sleek hold ribbons ($4\text{pt}$ wide) for longer notes ($d > 12\text{t}$) shaded with high-contrast print tones.
3. **Web Print Integration (`@media print`)**:
   - Dedicated print view / modal and Print button in `ControlsDrawer`.
   - CSS `@page { size: A4 portrait; margin: 10mm; }` ensuring clean pagination on phone browser (Pixel 10) and desktop.
4. **Network Printing Pipeline**:
   - Vector SVG/PostScript generator script (`scripts/print-score.ts`).
   - Relay script via `nacho-pi` over port 9100 to Brother HL-L3300CDW (`192.168.4.62`).
5. **Verification**:
   - Automated unit tests for columnar slicing, SVG generator, and print dimensions.
   - `npm test` passes cleanly.
   - `npm run build` succeeds cleanly.
