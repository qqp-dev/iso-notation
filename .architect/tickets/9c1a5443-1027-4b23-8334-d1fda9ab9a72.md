# Ticket: Lowercase 'm' Octave Markers (m1, m2, m3...)

## Kind

bounded — replace diatonic 'C' octave labels with lowercase 12-TET root phonetic markers (m1, m2, m3, m4, m5...).

## Problem

The operator noted that numbered "C" labels for octaves (e.g. `C2`, `C3`, `C4`, `C5`) do not make sense in a 12-TET isomorphic notation system with zero diatonic bias. In our canonical 12-TET phonetics, pitch class 0 is grounded on the consonant 'm' (syllable 'Ma'). Octave boundaries should be labeled with lowercase `m` followed by the octave number: `m1`, `m2`, `m3`, `m4`, `m5`, etc.

## Testing plan

1. **Lowercase 'm' Octave Marker Invariant**:
   - In `print-layout.ts`, pitch labels for PC 0 render as `m${oct}` (e.g. `m2`, `m3`, `m4`, `m5`), lowercase.
   - Zero occurrences of `C${oct}` or uppercase `C` octave labels.
2. **Canvas Octave Marker Invariant**:
   - In `score-canvas.ts`, PC 0 pitch indicators render as `m${oct}`.
3. **Verification**:
   - Unit tests verify `m${oct}` formatting and absence of diatonic `C` octave labels.
   - `npm test` passes cleanly.
   - `npm run build` succeeds cleanly.

## [bounded]

### Budget

1 quick iteration.

### Solution

1. In `src/render/print-layout.ts`:
   - Replace `<text ... class="pitch-label" font-weight="bold">C${oct}</text>` with `<text ... class="pitch-label" font-weight="bold">m${oct}</text>`.
2. In `src/render/score-canvas.ts`:
   - At `pc === 0`, render `m${oct}` instead of `0` or `0:${oct}` for the octave boundary label.
3. In `test/print-layout.test.ts` and `test/notation-variations.test.ts`:
   - Add/update tests asserting `m${oct}` markers.
