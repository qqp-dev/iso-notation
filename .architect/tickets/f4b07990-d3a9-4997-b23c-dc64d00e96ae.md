# Ticket: 12-TET Phonetic Representation Ordering

## Kind

bounded — straightforward mathematical optimization and interactive sandbox integration.

## Problem

Replacing multisyllabic pitch numbers with monosyllabic tokens across the 12-TET chromatic space for the 2-row Jánko keyboard.
Consonants agreed upon: `{B, D, F, K, L, M, N, P, R, S, T, V}`.
Vowel assignment agreed upon:
- Row 0 (Even whole-tone row): vowel `-a` -> `{fa, la, ma, na, sa, va}`
- Row 1 (Odd whole-tone row): vowel `-i` -> `{bi, di, ki, pi, ri, ti}`

The internal ordering of both 6-element sets needed to be resolved key-agnostically without assuming diatonic scales or linear step motion.

## Testing plan

1. Invariant: 100% of the 12 unique consonants are assigned bijectively to pitch classes 0..11.
2. Invariant: Row 0 keys (0, 2, 4, 6, 8, 10) use vowel `-a`; Row 1 keys (1, 3, 5, 7, 9, 11) use vowel `-i`.
3. Invariant: Acoustic cousins paired at the tritone (Delta = 6): Ma<->Na, Di<->Ti, Va<->Fa, Pi<->Bi, La<->Sa, Ri<->Ki.
4. Invariant: Augmented triad major thirds on Row 1 partitioned cleanly by voicing: {1, 5, 9} is 100% voiced (Di-Ri-Bi); {3, 7, 11} is 100% voiceless (Pi-Ti-Ki).
5. Mathematical conflict documented: Zero adjacent semitone collisions and tritone twin pairing are mutually exclusive by the Pigeonhole Principle (Group 0 has 3 alveolar ridge consonants; only 2 slots do not border Row 1's tritone-separated ridge consonants). The theoretical optimum is 1 collision (11/12 distinct).
6. Test suite `npm test` passes cleanly (23/23 tests passing).
7. Production build `npm run build` succeeds without errors.

## [bounded]

### Budget

1 session. Completed.

### Solution

Implemented interactive `PhoneticSandbox.tsx` loaded into `App.tsx` with:
- Prime 92% Optimal preset (`Ma -> Di -> Va -> Pi -> La -> Ri -> Na -> Ti -> Fa -> Bi -> Sa -> Ki`) set as primary default.
- 11 interactive drills including Bach Goldberg Var 1 theme mm. 1-2, Circle of Fifths, Tritone Twins, and Row 1 Triangles.
- Pitch audition Web Audio synth integration.
- Markdown export and copy tools.

### Rabbit holes

- Enforcing 0 semitone place collisions: Causes 4 to 6 Circle of Fifths collisions and destroys tritone pairing. Solved by relaxing to 1 collision, which pairs nasal continuant `Na` with stop `Ti` (different manners).

### No-gos

- Do not assume diatonic scales (e.g. G major) or scalar linear motion as basis for ordering.
- Do not reintroduce velar twin `ga`.
