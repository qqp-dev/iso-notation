# Ticket: Duration-Class Coloring (Note Value = Color)

## Kind

bounded — straightforward duration-based color mapping and preset integration.

## Problem

Grid-snap coloring (DDR-style onset quantization) caused continuous rainbow strobing on Bach's dense 16th-note counterpoint because classical music continuously occupies all grid subdivisions. We need **Duration-Class Coloring**, where color encodes the actual **duration / note-value** of each note, ensuring that steady passages of 16th notes are visually unified and calm, and color shifts only when rhythmic note values change.

## Testing plan

1. **Duration Invariance (Zero Grid-Snap Strobing)**:
   - Every note's color is determined strictly by its `durationTicks` (relative to `ticksPerBeat = 48`):
     - 16th notes ($12\text{t}$): Crisp White / Silver (`#E2E8F0`).
     - 8th notes ($24\text{t}$): Vibrant Sky Blue (`#38BDF8`).
     - Dotted 8th notes ($36\text{t}$): Indigo (`#818CF8`).
     - Quarter notes ($48\text{t}$): Warm Amber (`#F59E0B`).
     - Dotted quarter notes ($72\text{t}$): Orange (`#FB923C`).
     - Half notes ($96\text{t}$) and longer ($144\text{t}$): Rose (`#F43F5E`).
   - In Bach Goldberg Variation 1, every single 16th note in a running stream has the exact same color—zero rainbow flickering between onsets.
2. **Active Note Glow**:
   - Active sounding notes during playback glow bright gold/white (`#FEF08A` / `#FACC15`).
3. **Preset & Controls Integration**:
   - Added `'duration-class'` to `ColorMode`.
   - Added `"Vertical Duration Classes + Parity Shapes"` preset and set as default.
   - Added to Color Mode dropdowns in the toolbar and `ControlsDrawer.tsx`.
4. **Verification**:
   - `npm test` passes (all unit tests updated and passing).
   - `npm run build` succeeds cleanly.
   - Live workbench at `http://100.102.70.49:5173`.
