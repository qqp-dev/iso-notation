# Ticket: Klavarskribo Bounded Measure Barlines & Gutter Beat Counter Column

## Kind

bounded

## Problem

In `src/render/score-canvas.ts`, measure barlines currently render with `ctx.moveTo(15, y); ctx.lineTo(width - 15, y);`.
This causes several visual and architectural flaws:
1. **Margin Spill**: The staff breadth is only from `staffMinX` (40px) to `staffMaxX` (~544px), but barlines sprawl 150+ pixels into empty void on the right and cut across margin labels on the left.
2. **Boundary Disconnect**: Beat Grid lines are bounded to `[staffMinX, staffMaxX]`, while barlines sprawl across the canvas, making the metric grid look broken and inconsistent.
3. **Weight Hierarchy**: Regular barlines at `rgba(255, 255, 255, 0.20)` lack authoritative anchor presence.
4. **Clunky Labels**: Repetitive `M1`, `M2`, `M3` labels hover above the sprawling line and visually compete with noteheads.

## Klavarskribo Engraving Solution

1. **Staff-Bounded Barline Anchors**:
   - In vertical canvas: Barlines must span strictly from `staffMinX - 4` to `staffMaxX + 4`. They must never spill into outer canvas margins (`15` or `width - 15`).
   - In horizontal canvas: Barlines span strictly from `staffMinY - 4` to `staffMaxY + 4`.
   - Contrast: Regular barlines should be crisp (`rgba(255, 255, 255, 0.55)`, 1.0px). Double / final barlines: `rgba(255, 255, 255, 0.85)`, 2.0px.
2. **Left-Gutter Beat Counter Column (`1 · 2 · 3`)**:
   - In Klavarskribo, beats within each measure are counted down the left gutter aligned with each pulse line.
   - In vertical canvas, when `options.showBeatGrid` is true:
     - Print subtle beat count number `1` at Beat 1 (aligned with the solid barline) in the left gutter (`x = staffMinX - 10`, `y = barY`).
     - Print subtle beat count numbers `2`, `3` (for 3/4) aligned with the dotted pulse lines (`x = staffMinX - 10`, `y = beatY`).
     - Font: `9px monospace`, `rgba(255, 255, 255, 0.40)`.
   - In SVG print layout (`src/render/print-layout.ts`):
     - When `layout.options.showBeatGrid` is true, add corresponding beat count labels in the column left gutter (`x = colStaffLeftPt - 6`).
3. **Clean Measure Numbering**:
   - Replace cluttered `M{barNumber}` on every bar with clean, discrete measure numbers in the left margin (e.g. `1`, `5`, `9` or boxed every 4 bars: `[1]`, `[5]`, `[9]`, etc.) positioned cleanly without slicing lines.
4. **Beat Grid & Barline Unification**:
   - Ensure the solid barline (Beat 1) and dotted pulse lines (Beats 2, 3...) share the exact same `[staffMinX - 4, staffMaxX + 4]` span.
5. **Abandon Connecting Notes / Beams in UI Toggle**:
   - Remove the `🎶 Beams` quick-toggle button from the floating toolbar on the page (`src/ui/App.tsx`).
   - Remove the `🎶 Elaine Gould Beams` checkbox from `src/ui/ControlsDrawer.tsx`.
   - Set default `showBeamGrouping: false` so notes render with clean, independent Klavar lateral stems.
   - The page quick toggles are now focused purely on the two clear contenders: `📏 Beat Grid` (Klavar pulse lines) and `⊏ Brackets` (Gutter beat brackets).

## Testing Plan

2. **Left-Gutter Beat Counter Invariant**:
   - Canvas unit test verifies beat counts `1`, `2`, `3` are rendered along the left margin when `showBeatGrid: true`.
   - SVG print layout unit test verifies beat counts in column margin when `showBeatGrid: true`.
