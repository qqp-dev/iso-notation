# Read-only source-route inventory

From the repository with dependencies installed:

```sh
node --import tsx scripts/inventory-source-routes.ts 'https://example.org/catalogue' 'https://example.org/publication.pdf'
```

Replace the illustrative URLs with **1–5 short, explicit public item or asset URLs**; no source URLs for the later Kinderszenen pilot are bundled here. JSON prints to stdout; redirect to an explicitly chosen **external** path only if needed. The CLI does not cache, crawl linked URLs, provision the studio, fetch copyrighted sources into Git, execute attachments or convert/render pages. It uses direct HTTP(S), no proxy credentials or cookies, and rejects IP literals, nonpublic DNS destinations, URL userinfo, nonstandard ports and unsafe redirects. Do not supply authenticated/secret-bearing links. Only a vetted public IPv4 is passed to the socket's pinned lookup; IPv6-only destinations are reported unsupported.

Limits per invocation: 5 inputs; 3 redirects per input; 40 recognizable HTML `href`/`src` asset leads (PDF/image/notation file extensions) **reported but not fetched**; 8 MiB per complete response; 8 s/request and 60 s total; 200 PDF pages, 24 EmbeddedFiles entries, 2 MiB total embedded bytes. PDF.js runs in a disposable memory-limited worker with a 5 s parser timer. Oversized/partial responses have **no complete-byte identity**. PDF metadata reports a hash only after complete bytes; PDF.js discovers EmbeddedFiles name-tree entries, **not every page annotation**. Unsupported PDF structures, encrypted files and size/time limits are reported as unknown/limited, never inferred as absent. PDF page count is not requested-piece coverage; compressed, JS-generated and unrecognized HTML access routes require human inspection. Recognizable encoding assets (including `.mscx`/`.mscz`) are extension-based candidates only, not parsed scores or supported imports. HTML link lists report `linksTruncated: true` when more than 40 recognizable distinct leads are present: absence from that list is not evidence of absence from the page. Embedded flipbook JSON image URLs and JS-generated links are not discovered; generic asset links may fill the bounded list. Use the documented command on Node 26 without disabling network family selection; its socket lookup supplies the correct all-address callback shape while retaining the vetted-IP pin and redirect vetting.

Output reports invocation UTC start/end and elapsed milliseconds; requests attempted/completed/failed, HTTP non-successes, redirects and measured received response bytes (complete responses plus any explicitly measured failed-stream bytes; timeout-aborted streams may have unaccounted partial bytes). DNS failures occur before request attempts; parser failures are distinct from transport failures. Every result explicitly leaves human readability, per-piece page access, editorial authority, rights, score fidelity and studio readiness **unverified**. Use the [source-route record](../../.agents/skills/score-research/references/source-route-record.md) for independent, dated human observations; any actual studio handoff needs separately reviewed and authorized data.
