# ISO Practice rendered view · contract 1 (preview)

`renderPracticeView(request)` from `src/render/janko/practice.ts` is the isolated ISO core. It has no dependency on the studio, browser DOM, or Music Box. This is a visual iteration, **not** a Windows executable, WebView2 requirement, or final delivery package. The existing live studio's Candidates view displays its exact SVG; Bach GOLD and Brahms BRONZE References remain unchanged. Final guide aesthetics and the consumer host/transport require review with Music Box (currently PowerShell 5.1/WinForms, no confirmed Node/WebView2 prerequisite).

## Inputs and outputs

```ts
renderPracticeView({ rudiment: 'scale', scaleType: 'major', tonicLinear: 48,
  width: 760, height: 380, guide: 'two-guides' });
```

- `tonicLinear` is the **absolute** linear pitch index `12 * octave + pitchClass` (`C4 = 48`), not MIDI (`MIDI = tonicLinear + 12`). A UP/DOWN request changes this index by ±1 (a 1-span). The renderer resolves everything else. Supported integer tonics: 36–60 inclusive. Exact input selection, dimensions and guide treatment are explicit; unknown rudiment/scale/guide, non-finite sizes or out-of-range tonic throw `RangeError`.
- `width` 560–1600 and `height` 360–900 are available viewport dimensions in CSS pixels, also used as SVG user coordinates; intrinsic `width`/`height` are emitted in `px` (e.g. `760px × 380px`). Preserve aspect ratio when embedding. At extreme tonics and low heights the renderer may throw if the rails cannot fit; resize and retry rather than clipping or shrinking the symbols. Default guide is `two-guides`; `none` removes only the continuous guides.
- Return: `{svg, selectionId, isoVersion, contractVersion, guide, attacks, systemCount, railClearance}`. `svg` is the **complete** SVG string, pitch-black with embedded URW Gothic Demi OTF for the real engine pitch numerals; no asset URL, global CSS or studio dependency. `selectionId` is stable `scale:major:<tonicLinear>` and intentionally does **not** encode guide or viewport. `attacks` report each index, exact absolute pitch, onset tick, real engine x, and separately owned `hands.RH` and `hands.LH` `{finger,row,y}`. Indexes/ticks align 1:1. `contractVersion = 1`; `isoVersion = 0.1.0`. The embedded font is sourced from the project's `public/fonts/URWGothic-Demi.otf`.
- One sequence (15 quarter-note attacks) ascends the major steps `[0,2,4,5,7,9,11,12]` then descends `[11,9,7,5,4,2,0]` without an extra apex. The RH input `23412312`, LH input `43213214` and **alternative** physical rows `33324423` (even tonic) or `22213312` (odd tonic) drive both independent rails, with descent provisionally reversing the first seven cues. The row is a **vertical position**, not a printed row-number string. Rows 1 and 3 accept even-class pitches; rows 2 and 4 accept odd-class pitches. This is a first visual proposal, not an operator-approved descending fingering.
- RH is always the upper rail, LH the lower, both above **one** engine-engraved pitch staff. Each has four fixed row heights (row 1 lowest / nearest, row 4 highest / farthest); the two-guide treatment draws **two faint mid-row guides per hand** (four total), never through a numeral. Conventional fingers are amber sans-serif 1–5 versus white URW Gothic absolute pitch symbols. Cue `x` is taken from `layoutJankoScore`, and the staff is emitted by `renderSystem`. Palette transformation applies only to that output; white knockouts become opaque black **on the original paint layer**, preserving their protective order. No GOLD/default engine ink changes. `railClearance` is a conservative gap (SVG user units) from the lowest *possible* rail digit seat to this quarter-note fixture's actual positioned notehead/stem-top envelope and the engine's staff-top coordinate, with a 1-unit stroke pad. It is **not** general collision certification for future beams, flags, ottavas or arbitrary scores; the canonical linter does not inspect these rails.

`test/janko-practice.test.ts` pins the deterministic integration fixture: tonic 48/49 pitches, raw fingers and alternative row strings, reversible descent, 1-span transposition, separate hand alignment, geometry clearance, two guides versus none, embedded font, one system, rejection cases, studio use of the exact renderer, and unchanged Reference. The `test/fixtures/practice-v1.json` file provides consumer-readable inputs and expected identities/arrays. No audio, playback or full-score tablature is provided.

**Consumption boundary:** Music Box owns its selector, UP/DOWN events and hosting. ISO will determine final asset/distribution format and Windows host compatibility with the consumer architect after visual judgment; compiling the browser ESM bundle is **not** proof that PowerShell/WinForms can render an SVG or load its embedded font.
