An approved hand/engraving change targets an **active SCORE** directly. `Candidates` is optional for explicitly requested parallel full-score variants; there is no before/after maturity stage or promotion command. Bach remains GOLD, Brahms BRONZE. The immutable source builders are the historical baseline; the score-keyed `src/scores/data/active-scores.json` revision is the active overlay read by Reference, root Play/Sheet and the PDF exporter. Duration request: `{"schema":1,"intent":"engrave-duration","score":"brahms-op118-no1","base":"<current-revision>","tokens":{"halfRingGap":0.15}}`. No `variantId` is allowed on this active intent; private optional comparison requests instead require a named variant ID. Permitted controls are `exceptionCarrier` horizontal/symbol, bounded `halfRingGap`/`detachedSymbolAir`/`horizontalMountAir`, and up to eight full-owner `above`/`beside` placement targets with the existing fit/refusal validation. These are **engraving** controls; they never change any note's `durationTicks` or create/delete an event. An unknown control or unsupported combination is rejected.
