# Reusable source-route record (research handoff, not a source registry)

Copy only relevant fields. Date observations and live-recheck mutable URLs before any provisioning; distinguish **observed fact**, **publisher claim**, **inference**, **unknown**, and **operator decision**. This is neither engraving authority nor an approved edition. Only reviewed/authorized data enters the existing typed studio registry in separately scoped work.

- Work identity: composer / work / requested piece IDs / aliases / instrument; request and date (UTC).
- Editorial target (proposed or operator-selected): edition/editor/plate/witnesses/apparatus and reasoning **independent of encoding availability**; access/cost/rights limits.
- Route: item URL; original PDF/image URL(s); attachment and mirror URLs; publisher/holding institution, dated provenance; redirects and current live recheck (timestamp, outcome). Distinguish publication scope from requested-piece scope. Claims about licensing do not grant redistribution.
- Requested-piece coverage (repeat for each piece; original order, including intervening pages): `piece | original page + printed label | PDF 1-based index OR image frame/ID | inspected / missing / withheld / unverified | observation URL + date | claimed/inferred/unknown notes`. Do not infer labels from indices or page counts; if mapping unknown, record unknown. Include candidate beginning/end/texture/contested-passage anchors with inspection state, not merely a first-page guess.
- Starter route **separate from reference**: item and asset URL, encoding type/version/hash only if complete bytes observed, encoder and parent edition, license claim versus verified permission, proposed corresponding piece/measure anchors with independently checked mapping; reliability and unresolved discrepancies.
- Decision: desired vs available reference and starter, access/quality tradeoff needing operator judgment, per-piece gaps, next live recheck and separately authorized certification/studio handoff. State what is actually served versus proposed. No human coverage, notation fidelity, edition selection or rights is inferred from HTTP success, hashes, PDF page counts or attachment discovery.

Known example, **not a general page rule**: the Op. 68 comparison required checking real intermediate reference pages and independent starter anchors rather than inferring coverage from a PDF's existence. Consult the existing [Op. 68 dossier](../../../../docs/research/schumann-source-comparison.md) for its dated, work-specific evidence (and recheck links live). Its mixed-reference decision does not authorize a downgrade for another work.
